# Glyph Audit Review State

This directory holds durable, human-authored glyph-family review state.

`saved_families.jsonl` is an imported, read-only registry in this standalone
repository. The standalone family viewer does not write it: its source
repository's `s` save action was deliberately removed. Each JSONL row records
one reviewed or source-observed family:

```json
{"mode":"spin","size":4,"block":"Arrows","cps":[8592,8593,8594,8595],"chars":"<glyph chars>"}
```

Regenerable glyph feature caches stay under `.run/glyph_audit/`. Manual review
choices do not: they are tracked here so cache cleanup cannot erase them.

The registry was extracted with 81 nonblank rows and now carries 15 additional
rows observed in the Y9-2 source checkout on 2026-08-31. Those additions are
source evidence, not a claim that every row is generated by the standalone
viewer. In particular, the three `stroke` rows are retained for provenance but
the current standalone viewer exposes no `stroke` axis.
