# Review artifacts

This directory contains committed snapshots of generated review surfaces. The
live commands still rebuild local working copies under `.run/`; these files are
for repository review, sharing, and provenance.

## Glyph combo gallery

- `glyph_combo_gallery.html` is the self-contained HTML generated by
  `python3 scripts/glyph_combo_gallery.py` on 2026-09-08.
- It embeds the measured data for the full `COMBOS` review surface: authored
  Stone Story seeds, mined tutorial-plate runs, measured seam pairs, and
  generated Unicode/Kana/CJK/Arabic run buckets.
- Source cache inputs were the standalone repo's ignored `.run/glyph_audit`
  files at the time of generation.
- The generator reported 148,016 measured two- and three-cell plate-alphabet
  candidates before adding whole-repertoire seam and run buckets.

Verify the snapshot with:

```sh
(cd docs/artifacts && shasum -a 256 -c SHA256SUMS)
```
